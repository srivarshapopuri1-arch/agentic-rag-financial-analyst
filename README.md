# Agentic RAG Financial Analyst

A portfolio-scale financial research assistant using RAG, LangGraph orchestration, specialized financial-analysis tools, citations, and grounding validation.

> For research and portfolio demonstration only. Not investment advice.

## Architecture

Public financial PDFs -> parsing/chunking -> embeddings/vector store -> LangGraph research/analysis/validation workflow -> cited answer -> Streamlit UI.

## Status

The project is being built incrementally with public/sample financial data only. API keys, private data, local vector indexes, and PDFs are excluded from Git.
